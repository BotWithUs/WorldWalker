# Region-jumping transitions: two classes, frontier seeding, and a teleport-aware heuristic

Transitions that link distant regions are handled as two distinct classes. **Point-to-point** transitions (stairs, ladders, fairy rings, dungeon entrances, boats) are baked as ordinary directed edges in the abstract graph, even when the destination is thousands of tiles away — bounded in count, no special casing. **Global teleports** (lodestones, home, `global` spell teleports) are usable from almost anywhere, so baking per-cluster edges would produce millions of edges; instead they are **not baked at all** and are injected at query time by seeding the search frontier with each enabled destination at its tick cost (gated by the start tile being teleport-allowed). Teleporting from a mid-route point is covered by the Executor re-planning once it reaches a teleport-allowed tile, rather than modeled in a single search.

Wiring point-to-point edges forces the build to decode **all populated regions first** (a destination can be anywhere), which is fine since the artifact precomputes the whole world. Each endpoint is resolved to the nearest walkable tile within a small radius (dataset coords are often recorded on the object, not the standing tile); edges with no walkable tile in range are dropped and logged for dataset review. Region-jumping ladders/stairs are therefore **dataset-only** — cache derivation deliberately only auto-pairs locally vertical (same x,y, ±1 plane) ladders/stairs, so it never invents a far-region link.

Teleports break the spatial distance-to-goal heuristic (a teleport near the goal makes the true cost from a far node tiny, so distance overestimates → inadmissible → either wrong paths or a full Dijkstra fan-out across all regions). We use an **ALT (landmark) heuristic**: distances from a few landmarks to all abstract nodes are precomputed on the full graph (teleports included), giving a triangle-inequality bound that "knows" about shortcuts and keeps A* focused. Because removing edges only lengthens true paths, the full-graph landmark bounds stay admissible even when per-query capability disables transitions — so ALT is robust to requirement filtering. Contraction Hierarchies were rejected for v1: vanilla CH assumes a fixed graph, which the capability-dependent edge set violates.
