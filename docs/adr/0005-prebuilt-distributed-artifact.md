# Artifact is prebuilt and distributed, not built on the client

The baked collision/graph artifact is regenerated by a build step when the cache updates and distributed to clients (bundled in `data.zip` or downloaded by the loader, like `NXTCache.dll`). Clients only download and memory-map it. The artifact header stamps a format version and the cache revision it was built from: a **format** mismatch is a hard refuse (code/artifact incompatibility), a **cache-revision** mismatch is a soft warning so a freshly-updated game still walks on a slightly-stale artifact until the new one ships.

We chose this over building on the client from its local jcache (which would guarantee freshness but make every client pay a multi-second-to-minute build, and ship the whole map-decode path to clients). The accepted cost: an ops/build step per cache revision and a freshness window after each game update. Distribution piggybacks the existing native-artifact delivery mechanism.
